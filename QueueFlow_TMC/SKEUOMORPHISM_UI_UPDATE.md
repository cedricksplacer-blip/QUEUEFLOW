# QueueFlow TMC — Skeuomorphism UI Update

The interface has been restyled with a skeuomorphic visual language:
- beveled buttons and tactile pressed states
- metallic/light physical panels
- inset form fields
- raised cards and statistics
- textured/gradient sidebar and header
- skeuomorphic tables, badges, alerts, modals and authentication surfaces
- responsive-friendly styling retained

Main stylesheet: `public/css/skeuomorphism.css`
Source design system: appended to `resources/css/app.css`
